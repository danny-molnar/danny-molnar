# Danny Molnar

Cloud Engineer at **SoSafe**, working across robust cloud infrastructure, developer experience, and the safe adoption of AI-driven engineering.

I build tools and models that make complex systems easier to observe, interpret, and change. That work tends to meet somewhere between infrastructure engineering, programming-language design, and systems thinking.

> Robust infrastructure. Safer AI adoption. Better developer experience.

## Writing

I write [**The Sublime Infrastructure**](https://thesublimeinfrastructure.substack.com/): essays connecting practical infrastructure engineering with systems thinking, philosophy, economics, category theory, and topology.

